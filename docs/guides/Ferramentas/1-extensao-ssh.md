Para a configuração do PC2, que está dentro do robô G1, é recomendado utilizar a seguinte extensão do Visual Studio Code por conta do grande volume de arquivos a serem alterados.

<img src="/img/guides/teleoperacao/SSH1.png" alt="Primeiros 3 passos para baixar a extensão Remote - SSH." width="1500" />

A partir do quinto passo pode ser pedido a senha do G1, por padrão é `123`. Fica a escolha do pesquisador alterar os arquivos pelo Visual Studio Code ou pelo próprio terminal.
